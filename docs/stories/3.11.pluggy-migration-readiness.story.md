# Story 3.11: Prontidão para migração gradual ao Pluggy

**Status:** Done  
**Epic:** [EPIC-3](../epics/epic-3-pluggy-carteira-real-e-saude-financeira.md)  
**Prioridade:** Medium  
**Dependência:** Stories 3.8 e 3.10

## Objetivo

Formalizar a decisão de migração da carteira manual para o Pluggy sem desligar o CRUD atual antes de uma reconciliação explícita e verificável.

## Escopo

- Reutilizar o dual-read para calcular prontidão de migração.
- Bloquear a troca quando houver divergência de totais/tickers, posições não mapeadas ou cobertura manual incompleta.
- Expor modo atual, fonte candidata, bloqueadores e próxima ação.
- Manter `GET /api/portfolio/summary`, transações e fundos manuais inalterados.
- Disponibilizar endpoint autenticado e CLI somente leitura.

## Fora de escopo

- Apagar tabelas ou registros manuais.
- Alterar automaticamente a fonte ativa da carteira.
- Executar migração destrutiva ou copiar dados entre fontes.
- Fazer deploy ou alterar o ambiente de produção.

## Critérios de aceitação

- [x] O modo atual permanece `MANUAL` até uma decisão explícita posterior.
- [x] Divergência no dual-read bloqueia a troca para Pluggy.
- [x] Investimentos sem mapeamento estratégico bloqueiam a troca e aparecem nos bloqueadores.
- [x] O contrato informa `canSwitchToPluggy`, `manualCrudStatus`, bloqueadores e próxima ação.
- [x] Endpoint exige sessão e CLI/HTTP não expõem credenciais ou `rawData`.
- [x] Rotas manuais continuam funcionando sem alteração.
