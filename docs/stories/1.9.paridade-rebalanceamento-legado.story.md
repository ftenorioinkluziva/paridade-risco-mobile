# Story 1.9: Paridade Funcional da Tela de Rebalanceamento

## User Story

Como investidor,
Quero um rebalanceamento com o mesmo nivel de detalhe do legado,
Para executar ajustes de carteira com previsibilidade de custo e saldo.

## Objective

Implementar o fluxo de rebalance com base na cesta ativa, toggle de caixa na base de calculo e recomendacoes detalhadas por ativo.

## Scope

- Exibir bloco de base de calculo com valor investido, caixa e base final
- Adicionar toggle incluir/excluir caixa no calculo
- Exibir custo de rebalanceamento e saldo apos rebalance
- Exibir recomendacoes detalhadas com atual x alvo e progresso

## Out of Scope

- Execucao automatica de ordens

## Tasks

- [x] Expandir endpoint de rebalance preview com parametro includeCash
- [x] Retornar custo estimado e saldo projetado apos rebalance
- [x] Ajustar calculo de recomendacoes com e sem caixa
- [x] Atualizar tela mobile para novo painel de rebalance
- [x] Preservar regra de elegibilidade por perfil

## Acceptance Criteria

1. Usuario consegue alternar incluir/excluir caixa e ver impacto imediato no plano
2. Tela exibe custo e saldo projetado apos rebalance
3. Recomendacoes mostram atual x alvo por ativo com clareza
4. Elegibilidade por perfil continua sendo aplicada antes de liberar plano

## Testing

- Teste API de preview com includeCash true/false
- Smoke mobile com alternancia de caixa
- Teste de regressao da elegibilidade de perfil
