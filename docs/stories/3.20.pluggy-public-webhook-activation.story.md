# Story 3.20: Ativação operacional do webhook Pluggy

**Status:** Pending  
**Prioridade:** Medium  
**Dependências:** Stories 3.5 e 3.19  
**Escopo:** configuração operacional fora do ambiente local

## Objetivo

Disponibilizar o endpoint de webhook do Paridade de Risco em uma URL HTTPS pública e cadastrá-lo no Dashboard Pluggy, permitindo validar a entrega de eventos reais do Sandbox.

## Critérios de aceitação

- [ ] API publicada em staging ou outro ambiente HTTPS público.
- [ ] Endpoint `/api/integrations/pluggy/webhook` acessível publicamente sem expor credenciais.
- [ ] URL e segredo do webhook cadastrados no Dashboard Pluggy.
- [ ] Evento real do Sandbox recebido, deduplicado e processado pelo worker.
- [ ] Entrega, resposta HTTP, retry e falha observáveis em `/pluggy-eventos`.
- [ ] Nenhuma credencial ou segredo commitado no repositório.

## Plano de execução

1. Escolher o ambiente público de staging.
2. Configurar as variáveis Pluggy no ambiente de hospedagem.
3. Publicar a API e validar o healthcheck.
4. Cadastrar a URL HTTPS e o segredo no Dashboard Pluggy.
5. Gerar ou aguardar um evento Sandbox e confirmar o processamento ponta a ponta.

## Pendência atual

O endpoint e o processamento já estão implementados localmente. A execução aguarda somente uma URL HTTPS pública acessível pelo Pluggy e o cadastro operacional correspondente no Dashboard.
