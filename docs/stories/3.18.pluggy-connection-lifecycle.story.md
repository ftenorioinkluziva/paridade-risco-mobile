# Story 3.18: Ciclo de vida e reautorização Pluggy

**Status:** Done  
**Epic:** [EPIC-3](../epics/epic-3-pluggy-carteira-real-e-saude-financeira.md)  
**Prioridade:** High  
**Dependência:** Stories 3.5 e 3.17

## Objetivo

Tornar estados de conexão Pluggy acionáveis para o usuário, especialmente erros, espera de autorização e ação pendente no provedor.

## Critérios de aceitação

- [x] A projeção expõe status, expiração de consentimento e último erro da conexão.
- [x] Eventos `item/error`, `item/waiting_user_input` e `item/waiting_user_action` atualizam a conexão.
- [x] A tela `/pluggy` destaca conexões que exigem ação.
- [x] O usuário consegue tentar uma nova sincronização sem alterar mapeamentos ou dados manuais.
- [x] A orientação deixa claro quando é necessário reconectar a instituição pelo fluxo Pluggy.
- [x] Estados normais continuam sem alerta visual adicional.

## QA

- [x] Typecheck e lint aprovados.
- [x] Build Docker aprovado.
- [x] Smoke autenticado da tela `/pluggy` após reinício do serviço.
- [x] Contrato de projeção inclui os campos necessários sem credenciais ou payload bruto.
