# Story 1.6: Paridade Funcional da Tela de Posicoes

## User Story

Como investidor,
Quero visualizar minhas posicoes com os mesmos indicadores operacionais do legado,
Para decidir ajustes de carteira com seguranca.

## Objective

Implementar os indicadores e a listagem detalhada de posicoes com consistencia de calculo em relacao ao portfolio consolidado.

## Scope

- Exibir cards de topo (valor total, posicoes, ganho/perda, caixa)
- Exibir lista detalhada por ativo com shares, preco medio, preco atual, valor e pnl
- Garantir alinhamento do total com as bases de fundos e caixa

## Out of Scope

- Otimizacoes de design sem impacto funcional

## Tasks

- [x] Expandir contrato de portfolio summary para suportar todos os indicadores
- [x] Ajustar endpoint de portfolio para retornar posicoes detalhadas
- [x] Atualizar tela de posicoes no mobile
- [x] Validar consistencia com rebalance preview

## Acceptance Criteria

1. Indicadores de topo batem com calculo consolidado (posicoes + fundos + caixa)
2. Cada ativo exibe metrica operacional completa
3. Ganho/perda absoluto e percentual ficam coerentes com os dados de preco
4. Valores apresentados sao consistentes com rebalanceamento

## Testing
