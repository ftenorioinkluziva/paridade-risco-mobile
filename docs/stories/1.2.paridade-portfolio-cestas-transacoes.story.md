# Story 1.2: Paridade Funcional de Portfolio, Cestas e Transacoes

## User Story

Como investidor,
Quero visualizar e operar meu portfolio/cestas/transacoes com comportamento consistente,
Para confiar nos dados exibidos e nas acoes do app.

## Objective

Eliminar inconsistencias pos-migracao e estabilizar os fluxos core financeiros.

## Scope

- Revisar calculos de resumo e desvio
- Validar fluxo de cesta ativa e detalhes
- Garantir criacao/listagem de transacoes sem regressao

## Out of Scope

- Novas features de produto fora do core
- Simulacao de aposentadoria e fundos

## Tasks

- [ ] Validar regras de resumo de portfolio com dados migrados
- [ ] Ajustar casos sem cesta ativa e sem transacoes
- [ ] Revisar fluxo de detalhe/edicao de cesta
- [ ] Validar consistencia de listagem e insercao de transacoes

## Acceptance Criteria

1. Portfolio summary responde sem erro para usuarios migrados
2. Tela de cestas nao quebra em estado vazio
3. Nova transacao aparece na listagem apos insercao
4. Rebalance preview responde com base na cesta selecionada

## Testing

- Smoke end-to-end: overview -> cestas -> transacoes -> rebalance
- Teste com usuario migrado e usuario novo
