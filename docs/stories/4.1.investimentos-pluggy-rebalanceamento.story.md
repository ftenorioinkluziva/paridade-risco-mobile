# Story 4.1: Carteira de investimentos Pluggy com rebalanceamento

**Status:** Done  
**Prioridade:** Critical  
**Dependências:** Epic 3

## Objetivo

Criar uma tela única para o usuário entender os investimentos observados pelo Pluggy, a cobertura da análise e o plano de rebalanceamento da cesta ativa.

- [x] Rota `/investimentos` autenticada e disponível no menu principal.
- [x] Mostra patrimônio observado, valor estratégico, cobertura e caixa disponível.
- [x] Mostra a decisão do motor e o drift; apresenta as ações de comprar/reduzir em um quadro separado com percentuais atual/alvo.
- [x] Expõe mapeados, pendentes, fora da estratégia e posições sem custo médio.
- [x] Lista as posições observadas e direciona a revisão detalhada para `/pluggy`.
- [x] Exibe frescor e origem dos dados.
