# Story 1.17: Login com Better Auth

## User Story

Como usuario autenticado,
Quero login, cadastro e recuperacao de senha modernos e seguros,
Para acessar o app com confiança e facilidade.

## Objective

Migrar o sistema de autenticacao para Better Auth, mantendo coexistencia com o session resolution atual para MCP/CLI/Telegram.

## Scope

- Configurar Better Auth com Drizzle adapter (PostgreSQL)
- Email/password login com Better Auth
- Cadastro de novos usuarios (signup)
- Recuperacao de senha mantida em log nesta etapa, por decisao do produto em 2026-08-20
- RBAC com admin() plugin (substituir enum ADMIN/USER)
- Sessoes cookie-based para web PWA + Bearer para MCP/CLI
- Middleware de protecao de rotas

## Out of Scope

- Remover tabelas antigas (users, sessions) — fica para story futura
- Integracao com provedores OAuth (Google, GitHub, etc.)
- Migrar MCP/CLI/Telegram para Better Auth session resolution

### Configuracao Better Auth

```typescript
// apps/api/src/lib/auth.ts
import { betterAuth } from "better-auth";
import { drizzleAdapter } from "better-auth/adapters/drizzle";
import { nextCookies } from "better-auth/next-js";
import { admin as adminPlugin } from "better-auth/plugins";
import { db } from "@/db/client";
import { ac, admin, user } from "@/lib/permissions";

export const auth = betterAuth({
  appName: "Paridade Risco",
  database: drizzleAdapter(db, {
    provider: "pg",
    usePlural: true,
  }),
  emailAndPassword: {
    enabled: true,
    disableSignUp: false,
    requireEmailVerification: false, // habilitar depois
    minPasswordLength: 8,
    maxPasswordLength: 128,
    autoSignIn: true,
    sendResetPassword: async ({ user, url, token }) => {
      // TODO: integrar com servico de email
      console.log(`Password reset for ${user.email}: ${url}`);
    },
    resetPasswordTokenExpiresIn: 3600, // 1 hora
  },
  plugins: [
    adminPlugin({
      ac,
      roles: { admin, user },
    }),
    nextCookies(), // ultimo plugin
  ],
});
```

### Middleware

```typescript
// apps/api/src/middleware.ts
import { NextRequest, NextResponse } from "next/server";
import { getSessionCookie } from "better-auth/cookies";

export async function middleware(request: NextRequest) {
  const sessionCookie = getSessionCookie(request);
  const { pathname } = request.nextUrl;

  if (sessionCookie && ["/login", "/signup"].includes(pathname)) {
    return NextResponse.redirect(new URL("/", request.url));
  }

  if (!sessionCookie && !pathname.startsWith("/api") && pathname !== "/login" && pathname !== "/signup" && !pathname.startsWith("/reset-password")) {
    return NextResponse.redirect(new URL("/login", request.url));
  }

  return NextResponse.next();
}

export const config = {
  matcher: ["/((?!_next/static|_next/image|favicon.ico|manifest.json|sw.js).*)"],
};
```
