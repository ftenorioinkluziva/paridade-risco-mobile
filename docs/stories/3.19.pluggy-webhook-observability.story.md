# Story 3.19: Observabilidade e reprocessamento de eventos Pluggy

**Status:** Done  
**Epic:** [EPIC-3](../epics/epic-3-pluggy-carteira-real-e-saude-financeira.md)  
**Prioridade:** High  
**Dependência:** Stories 3.5 e 3.18

## Objetivo

Dar visibilidade operacional aos webhooks recebidos e permitir reprocessamento controlado sem expor payloads financeiros brutos.

## Critérios de aceitação

- [x] Endpoint autenticado lista eventos somente da conta atual.
- [x] A resposta sanitizada informa evento, item, status, tentativas, timestamps e erro resumido.
- [x] Payload bruto não é retornado à interface.
- [x] Eventos `FAILED` e `IGNORED` podem ser reenfileirados pelo usuário autorizado.
- [x] O retry não permite reprocessar evento de outra conta ou evento em processamento.
- [x] A tela `/pluggy-eventos` permite atualizar a lista e acompanhar o processamento.
- [x] A navegação principal oferece acesso à observabilidade Pluggy.

## QA

- [x] Typecheck e lint aprovados.
- [x] Build Docker aprovou as rotas de listagem e retry.
- [x] Smoke autenticado mostrou o evento Sandbox `item/updated` processado, com uma tentativa.
- [x] A interface confirmou que o payload bruto não é exibido.
