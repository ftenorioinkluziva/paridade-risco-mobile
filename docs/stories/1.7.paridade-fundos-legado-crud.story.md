# Story 1.7: Paridade Funcional da Tela de Fundos com CRUD Completo

## User Story

Como investidor,
Quero gerir meus fundos com o mesmo fluxo do legado,
Para manter minha carteira consolidada e o rebalanceamento correto.

## Objective

Completar paridade da tela de fundos com resumo, listagem completa, criacao, edicao, exclusao e atualizacao rapida de valor.

## Scope

- Exibir resumo de fundos (total investido, valor atual, ganho/perda, rentabilidade)
- Exibir listagem detalhada de fundos com metadados
- Implementar update e delete na API de fundos
- Implementar UX de editar/excluir/atualizar valor no mobile

## Out of Scope

- Integracoes externas de precificacao automatica

## Tasks

- [x] Adicionar PUT e DELETE no endpoint de fundos
- [x] Adicionar endpoint de update de valor atual
- [x] Criar tela dedicada de fundos no mobile
- [x] Implementar acoes de criar/editar/excluir/atualizar valor
- [x] Refletir alteracoes em portfolio summary e rebalance preview

## Acceptance Criteria

1. Usuario consegue criar, editar, excluir e atualizar valor de fundo
2. Resumo de fundos apresenta metrica de rentabilidade correta
3. Alteracao de valor do fundo afeta portfolio e rebalanceamento em tempo de uso
4. Tela de fundos replica o fluxo operacional do legado

## Testing

- Testes API para GET/POST/PUT/DELETE de fundos
- Smoke mobile de CRUD completo
- Teste de impacto de valor atualizado no rebalance
