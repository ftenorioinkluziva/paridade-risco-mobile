# Story 3.12: Revisão de mapeamentos Pluggy na interface

**Status:** Done  
**Epic:** [EPIC-3](../epics/epic-3-pluggy-carteira-real-e-saude-financeira.md)  
**Prioridade:** High  
**Dependência:** Stories 3.6 e 3.11

## Objetivo

Permitir que o usuário revise os investimentos Pluggy observados e aprove explicitamente seus vínculos com ativos estratégicos, reduzindo os bloqueadores do dual-read sem mapeamento automático.

## Critérios de aceitação

- [x] A tela lista investimentos Pluggy, valor, status e candidato quando disponível.
- [x] O usuário escolhe explicitamente um ativo antes de aprovar o mapeamento.
- [x] A aprovação usa a API idempotente existente e a remoção é reversível.
- [x] A tela informa o estado atual do gate de migração e mantém o CRUD manual ativo.
- [x] Erros, carregamento e ausência de investimentos são visíveis.
- [x] Nenhuma credencial ou `rawData` aparece na interface.
