# Story 3.17: Painel de saúde financeira Pluggy

**Status:** Done  
**Epic:** [EPIC-3](../epics/epic-3-pluggy-carteira-real-e-saude-financeira.md)  
**Prioridade:** High  
**Dependência:** Stories 3.9, 3.10 e 3.16

## Objetivo

Transformar os contratos de visão financeira e saúde financeira Pluggy em uma experiência de decisão para o usuário, mantendo separadas carteira de risco, caixa, crédito, obrigações e dívida.

## Critérios de aceitação

- [x] Nova tela autenticada `/saude-financeira` consome os endpoints Pluggy existentes.
- [x] Exibe caixa bancário sem somar limite de cartão ao patrimônio.
- [x] Exibe fluxo de caixa, gastos no cartão e pagamentos excluídos para evitar dupla contagem.
- [x] Exibe faturas, vencimentos, pagamentos mínimos e obrigações próximas.
- [x] Exibe empréstimos com estado `DISPONIVEL`, `INCOMPLETA` ou ausência de registros sem inventar valores.
- [x] Exibe saúde geral e alertas explicáveis por severidade e origem.
- [x] Exibe fonte, período analisado e última sincronização Pluggy.
- [x] Atualização manual refaz as duas leituras sem alterar dados financeiros.
- [x] Navegação principal oferece acesso à tela sem remover os fluxos existentes.
