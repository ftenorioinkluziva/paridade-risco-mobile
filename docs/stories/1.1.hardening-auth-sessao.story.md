# Story 1.1: Hardening de Autenticacao e Sessao

## User Story

Como usuario autenticado,
Quero um fluxo de login/sessao confiavel e previsivel,
Para usar o app sem quedas de estado ou erros intermitentes.

## Objective

Reduzir falhas de autenticacao/sessao e padronizar tratamento de erro no mobile e API.

## Scope

- Revisar e padronizar respostas de erro da API de auth
- Garantir comportamento consistente no Web e mobile nativo
- Melhorar expiracao/invalidez de sessao no cliente

## Out of Scope

- RBAC completo
- Cadastro/recuperacao de senha

## Tasks

- [ ] Revisar contratos de /api/auth/login, /api/auth/me e /api/auth/logout
- [ ] Normalizar codigos de status e payload de erro
- [ ] Ajustar cliente mobile para estados de sessao invalida
- [ ] Cobrir cenarios de token invalido/expirado

## Acceptance Criteria

1. Login com credencial valida cria sessao e retorna usuario
2. Sessao invalida nao quebra tela e redireciona para login
3. Logout limpa sessao local e servidor
4. Erros de auth retornam mensagens consistentes para UI

## Testing

- Fluxo login/logout em Web e mobile
- Sessao expirada simulada
- Token invalido manual
