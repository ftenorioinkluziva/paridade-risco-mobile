# Story 4.5: Aporte planejado na prévia de rebalanceamento

**Status:** Done  
**Epic:** EPIC-4 — Experiência Pluggy e decisão financeira

## Objetivo

Permitir que o usuário informe quanto pretende aportar agora, usando o valor apenas como parâmetro de simulação para as ordens da carteira Pluggy.

## Regras

- O valor inicial é o caixa observado pelo Pluggy.
- O valor editado deve permanecer entre zero e o caixa observado.
- A base do cálculo é o valor investido mapeado mais o aporte planejado.
- A diferença entre o caixa observado e o aporte planejado permanece como reserva.
- O aporte planejado não altera o saldo Pluggy, a carteira persistida ou executa ordens.
- Pagamentos, limites de cartão e dados fora da estratégia não entram como caixa para ordens.

## Critérios de aceitação

- [x] `/investimentos` apresenta campo editável para o aporte planejado.
- [x] O valor padrão continua sendo o caixa observado.
- [x] Valores acima do caixa são limitados ao máximo disponível.
- [x] A prévia recalcula a base, as compras, as reduções e o caixa pós-plano.
- [x] A tela mostra caixa observado, caixa destinado às ordens e reserva mantida.
- [x] A rota aceita `cashForOrders` sem persistir a simulação.
- [x] O contrato MCP aceita `cashForOrders` como número decimal.

## Evidências

- Testes unitários do rebalanceamento cobrem o valor padrão e um aporte menor que o caixa.
- Typecheck e contratos compartilhados aprovados.
