# Story 3.16: Troca explícita da fonte da carteira para Pluggy

**Status:** Done  
**Epic:** [EPIC-3](../epics/epic-3-pluggy-carteira-real-e-saude-financeira.md)  
**Prioridade:** Critical  
**Dependência:** Stories 3.11, 3.14 e 3.15

## Objetivo

Permitir que o usuário aprove explicitamente a troca da fonte da carteira para Pluggy depois que o gate estiver pronto, fazendo os endpoints principais refletirem a integração real sem apagar o CRUD manual.

## Critérios de aceitação

- [x] A fonte ativa é persistida por usuário e começa como `MANUAL`.
- [x] A aprovação exige `canSwitchToPluggy=true` e é idempotente.
- [x] Após a aprovação, resumo da carteira e prévia principal de rebalanceamento usam Pluggy.
- [x] O modo atual e a fonte aplicada aparecem no contrato de prontidão e na UI.
- [x] Transações, fundos e dados manuais permanecem disponíveis durante a compatibilidade.
- [x] Uma tentativa bloqueada não altera a fonte ativa.
- [x] Nenhuma aprovação é executada automaticamente por smoke test ou carregamento de tela.
