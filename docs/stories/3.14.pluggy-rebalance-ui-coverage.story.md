# Story 3.14: Prévia de rebalanceamento Pluggy com cobertura

**Status:** Done  
**Epic:** [EPIC-3](../epics/epic-3-pluggy-carteira-real-e-saude-financeira.md)  
**Prioridade:** High  
**Dependência:** Stories 3.8 e 3.13

## Objetivo

Exibir na tela de rebalanceamento a prévia calculada sobre a carteira Pluggy, distinguindo aderência estratégica, ativos fora da estratégia e posições ainda pendentes.

## Critérios de aceitação

- [x] A tela exibe uma seção Pluggy separada da prévia manual durante a compatibilidade.
- [x] A seção mostra cesta alvo, drift, ordens indicativas, liquidez e base de cálculo.
- [x] A cobertura mostra o percentual do patrimônio de investimentos considerado pelo motor de risco.
- [x] Valores `FORA_DA_ESTRATEGIA` permanecem no patrimônio observado, mas não entram na aderência ou nas ordens.
- [x] Posições pendentes tornam a análise parcial e mantêm `executionReady` falso.
- [x] A UI deixa claro que ordens Pluggy são indicativas enquanto a migração não estiver pronta.
- [x] Erros, carregamento, ausência de cesta e perfil incompleto são visíveis.
