# Story 1.5: Campos de Perfil Legado e Elegibilidade de Rebalanceamento

## User Story

Como usuario,
Quero que meu perfil legado esteja completo na v2,
Para que regras de elegibilidade e recomendacoes de rebalanceamento sejam mais adequadas ao meu contexto.

## Objective

Reintroduzir campos de perfil legado (phone, role, dataNascimento, image) e conecta-los ao fluxo de rebalance.

## Scope

- Expandir schema de usuario na v2 com campos de perfil legado
- Atualizar API de perfil para leitura/escrita desses campos
- Definir e aplicar regras basicas de elegibilidade para rebalance

## Out of Scope

- RBAC completo por papel administrativo
- Fluxos avançados de onboarding

## Tasks

- [x] Adicionar campos de perfil no schema v2
- [x] Criar migracao para backfill inicial
- [x] Atualizar endpoint de perfil
- [x] Aplicar regra de elegibilidade no rebalance preview
- [x] Ajustar telas mobile para exibir/editar campos relevantes

## Acceptance Criteria

1. Campos de perfil legado existem e persistem corretamente na v2
2. API de perfil retorna os novos campos
3. Rebalance preview aplica regra de elegibilidade baseada no perfil
4. UI informa quando dados de perfil impedem recomendacao completa

## Testing

- Teste de API para leitura/escrita de perfil
- Teste de regra de elegibilidade no rebalance
- Smoke mobile para atualizacao de perfil e reflexo no rebalance
