# Story 3.15: Sandbox sem baseline manual fictício

**Status:** Done  
**Epic:** [EPIC-3](../epics/epic-3-pluggy-carteira-real-e-saude-financeira.md)  
**Prioridade:** High  
**Dependência:** Stories 3.11 e 3.14

## Objetivo

Permitir que o ambiente Pluggy Sandbox experimental valide a carteira conectada sem bloquear a prontidão por registros manuais fictícios usados apenas para demonstração.

## Escopo

- Tornar explícita por configuração a política de ignorar a carteira manual como baseline de reconciliação.
- Restringir essa política ao Sandbox; produção deve continuar exigindo reconciliação manual/Pluggy.
- Preservar a divergência no contrato de observabilidade, identificando que ela não foi considerada no gate.
- Continuar bloqueando posições Pluggy pendentes e manter a fonte manual até aprovação explícita.

## Critérios de aceitação

- [x] O Sandbox experimental não bloqueia o gate por totais/tickers da carteira manual fictícia.
- [x] A resposta informa a política de reconciliação aplicada e mantém o dual-read divergente visível.
- [x] Investimentos Pluggy pendentes continuam bloqueando `canSwitchToPluggy`.
- [x] Produção não pode ativar essa política por configuração acidental.
- [x] O modo atual continua `MANUAL` e nenhuma troca de fonte é executada automaticamente.
- [x] A UI informa que a comparação manual foi desconsiderada por ser baseline experimental.
