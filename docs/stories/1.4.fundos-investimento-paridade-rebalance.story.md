# Story 1.4: Fundos de Investimento na Paridade de Rebalanceamento

## User Story

Como investidor,
Quero que fundos de investimento sejam considerados no patrimonio consolidado,
Para que o desvio e as recomendacoes de rebalanceamento reflitam minha carteira real.

## Objective

Implementar suporte a fundos na v2 (schema, API e leitura no mobile) com impacto no calculo de rebalance.

## Scope

- Adicionar modelo de fundos no banco v2
- Expor endpoints de consulta/cadastro basico de fundos
- Integrar fundos no calculo de patrimonio/desvio para rebalance

## Out of Scope

- Gestao avancada de fundos com workflows complexos
- Simulacao de aposentadoria

## Tasks

- [x] Criar tabela de fundos no schema v2
- [x] Criar migracao e rotas API de fundos
- [x] Integrar fundos no resumo de portfolio e rebalance preview
- [x] Adicionar telas/listagens minimas no mobile
- [x] Validar com dados migrados do legado

## Acceptance Criteria

1. Fundos podem ser listados e persistidos na v2
2. Portfolio summary considera fundos no total consolidado
3. Rebalance preview reflete patrimonio incluindo fundos
4. Usuario com fundos ve diferenca coerente de desvio antes/depois

## Testing

- Teste de API: CRUD basico de fundos
- Teste de dominio: impacto de fundos no calculo de desvio
- Smoke mobile: visao de fundos + rebalance preview
