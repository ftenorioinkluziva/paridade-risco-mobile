# Story 4.4: Normalização dos empréstimos Pluggy

**Status:** In Progress  
**Prioridade:** High  
**Dependências:** Epic 3

## Objetivo

Normalizar o contrato real de Loans da Pluggy sem perder a distinção entre dados disponíveis e dados incompletos.

## Critérios de aceitação

- [x] `productName` é usado como nome do empréstimo.
- [x] `contractAmount` é usado como valor contratado.
- [x] `payments.contractOutstandingBalance` é usado como saldo devedor.
- [x] `interestRates[0].preFixedRate` é reconhecido quando não há taxa direta.
- [x] `dueDate` é preservado como vencimento contratual/maturidade, sem ser confundido com próxima parcela.
- [x] Campos ausentes permanecem nulos e o estado continua `INCOMPLETA`.
- [x] A tela de Saúde Financeira mostra o valor contratado e o vencimento contratual quando disponíveis.
- [ ] A parcela regular é confirmada contra um payload real que contenha o valor da prestação.
- [ ] Validar com uma instituição/conector que forneça Loans completos.

## Pendências

O Sandbox atual fornece saldo devedor, valor contratado, taxa e vencimento contratual, mas não fornece uma parcela regular no payload observado. A conclusão da story depende de validar esse campo em um conector com cobertura completa de crédito.
