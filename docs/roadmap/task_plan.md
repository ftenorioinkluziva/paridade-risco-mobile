# Task Plan - Roadmap de Implementacao

## Objetivo
Definir um roadmap executavel de curto prazo para evolucao do projeto paridade-risco-mobile apos bootstrap AIOX e migracao de dados.

## Fases

- [x] Fase 1: Levantar baseline atual (stories, estado de migracao, gates)
- [x] Fase 2: Definir prioridades por impacto x risco
- [x] Fase 3: Estruturar roadmap 30/60/90 dias
- [x] Fase 4: Publicar roadmap em documento de referencia
- [x] Fase 5: Quebrar o roadmap em stories executaveis
- [x] Fase 6: Registrar gap funcional legado x v2
- [x] Fase 7: Executar homologacao E2E das 4 telas e auditar importacoes pendentes do legado

## Criterios de sucesso

- Roadmap com milestones claros e entregaveis objetivos
- Backlog inicial de stories por fase
- Dependencias e riscos explicitos
- Metricas de acompanhamento definidas
- Stories iniciais criadas em docs/stories com escopo e AC claros
- Lista de funcionalidades do legado ainda nao cobertas na v2
