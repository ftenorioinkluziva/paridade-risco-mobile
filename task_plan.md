# Plano de Refinamento UI/UX (Passe Caprichado)

## Objetivo
Elevar o acabamento visual e consistencia de navegacao no app mobile sem alterar regras de negocio.

## Fases
- [x] Fase 1: Consolidar tokens de layout (espacamento, raio, toque)
- [x] Fase 2: Aplicar tokens em componentes base (`Screen`, `PrimaryButton`, `SegmentedControl`)
- [x] Fase 3: Harmonizar telas principais (Overview, Funds, Transactions, NewTransaction, Baskets, Rebalance, Profile)
- [x] Fase 4: Validar typecheck e revisar consistencia final

## Criterios de qualidade
- Coerencia de paddings e gaps
- Alvos de toque confortaveis
- Hierarquia visual clara para acoes
- Estados vazios e feedbacks com linguagem consistente
